# README COMPRIMI_01

## NOTE

COMPRIMI FILE: 
   Progetto per la compressione dei file su linea di comando, per ora comprime tutti i file
   che si trovano nella path di partenza e li comprime nella path di arrivo. Recupero la path
   di partenza e di arrivo dalle risorse di file di testo .txt.

MODALITA DI COMPRESSIONE   
   La compressione avviene creando un zipo con l'anno ed il mese di modifica dei file es.
   I file del 2023 modificati ad ottobre : PathDiPartenza_2023_10.7z
   Il nome del file viene costruito con il file_time.rs dal quale viene estratto il nome
   dell'anno e del mese in formato numerico ed utilizzato nella procedura di compressione.
   Vedi codice ---> @dal file_time.rs
